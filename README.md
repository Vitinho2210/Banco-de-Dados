**Banco de Dados**

O projeto de Banco de Dados foi desenvolvido com o objetivo de praticar a criação e a organização de estruturas de dados para representar informações de diferentes contextos. O projeto trabalha conceitos fundamentais de banco de dados, como organização de informações, tabelas e relacionamento entre os dados.

A atividade foi desenvolvida como parte dos estudos de Banco de Dados, permitindo colocar em prática conceitos apresentados em aula e compreender melhor como as informações podem ser estruturadas para facilitar seu armazenamento e utilização.

**Recursos utilizados:** banco de dados, tabelas, relacionamentos e comandos da linguagem SQL.
